# 概要
- USB PD or 12V DC jack(40Vまで許容)
- 12v-5v, 12v-3.3v, 5v-1.2v DCDCコンバータ搭載
- USB3.0*2
- USB2.0*2
- M.2 M key (NVME SSDのみ) 
- M.2 E key
- gigabit ethernet
- hd*iっぽいなにかの端子
- SDカードスロット
- stm32H723VGT6 搭載
- CANFD*2
- stm32 debug用コネクタ
